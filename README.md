# Solo Clipboard

一个基于 Rust 和 GPUI 开发的桌面剪贴板管理工具，支持长期保存剪贴板历史记录。

## 功能特性

- 📋 **自动监控剪贴板** - 后台自动捕获剪贴板内容变化
- 💾 **持久化存储** - 剪贴板历史记录保存到本地文件
- 🔍 **快速搜索** - 支持搜索历史剪贴板内容（开发中）
- ⌨️ **快捷键支持** - 通过快捷键快速调出窗口（开发中）
- 🎨 **现代化界面** - 使用 GPUI 构建的流畅用户界面
- ♾️ **无限历史记录** - 支持保存任意数量的剪贴板记录
- ✅ **批量删除** - 选择模式下批量删除多个条目
- 🗑️ **灵活删除** - 支持单项删除、批量删除和清空全部

## 技术栈

- **Rust** - 系统编程语言，高性能、内存安全
- **GPUI** - Zed 编辑器使用的 GPU 加速 UI 框架
- **clipboard-win** - Windows 剪贴板操作
- **serde/serde_json** - 数据序列化
- **chrono** - 时间处理

## 编译与运行

### 前置要求

- Rust 1.70+ (推荐使用 rustup 安装)
- Windows 10/11
- Git

### 编译

```bash
# 克隆项目（如果从 git 获取）
git clone <repository-url>
cd SoloClipboard

# 编译发布版本
cargo build --release

# 运行
cargo run --release
```

### 开发模式

```bash
# 运行开发版本
cargo run
```

## 使用说明

### 基本操作

1. **启动程序** - 运行程序后会自动开始监控剪贴板
2. **查看历史** - 主窗口显示所有剪贴板历史记录（最新的在上方）
3. **点击复制** - 点击任意历史记录即可重新复制到剪贴板
4. **保存历史** - 点击"保存"按钮将历史记录持久化到文件

### 删除操作

1. **单项删除** - 每条记录右上角有红色"删除"按钮，点击删除单条记录
2. **批量删除**：
   - 点击顶部"批量删除"按钮进入选择模式
   - 选择模式下，每条记录右侧显示复选框
   - 点击记录选中/取消选中
   - 点击"删除选中"按钮删除所有选中的记录
   - 点击"取消选择"退出选择模式
3. **清空全部** - 点击"清空全部"按钮清除所有历史记录

### 快捷键（计划中）

- `Ctrl + Shift + V` - 快速调出剪贴板历史窗口
- `Esc` - 关闭窗口
- `Ctrl + F` - 搜索历史记录

### 数据存储

历史记录保存在：
```
%LOCALAPPDATA%\SoloClipboard\history.json
```

## 注意事项

⚠️ **重要提示**：

1. 本项目依赖 Zed 编辑器的 GPUI 框架，该框架仍在快速迭代中，API 可能会有变化
2. 首次编译可能需要较长时间，因为需要编译 GPUI 及其依赖
3. 剪贴板监控每 500ms 检查一次，对系统性能影响很小
